# 提交证据复用（第一阶段）

本阶段接入 Codeforces 与 AtCoder；其余平台保留原同步流程。QOJ 奖励、难度档位和历史奖励流水不变。

账号同步每成功保存一页，同时保存奖励生效日期之后的提交 ID、绑定账号、题目和比赛 ID、精确提交时间、判题结果、来源及观察时间。相同提交重新读取时更新判题结果，不创建第二条记录。原首次 AC 记录仍用于累计统计和热力图，不能替代赛内提交证据。

只有完整完成历史查询才写入覆盖范围；失败、部分分页或缺少关键身份/时间字段不证明完整性。写入与账号分页进度在同一事务内，旧任务不能写入新账号进度。未知日期的旧记录不伪造时间、不直接迁移成提交证据。

比赛发现复用最近三十分钟内完整覆盖奖励起点之后的历史，并继续抓取覆盖范围之后的最新提交。比赛逐题核验只有在整个比赛时间范围已覆盖、证据仍新鲜、没有待判记录时复用本地提交，否则回到原有远端核验。题目目录和难度仍使用公共缓存。覆盖范围保守排除查询时最近十分钟，以缓冲索引延迟；超过三十分钟的覆盖需远端刷新，避免长期复用陈旧结果。第三方镜像无法提供绝对实时保证。

旧账号首次增量同步即可积累近期证据；若需要复用更早比赛历史，可执行已有的“完整同步”。完整同步分页执行，保留现有聚合数据及领取记录。

部署需应用 0069_submission_evidence 迁移并重建 Web、Worker、Beat。新表只增加证据，不自动发币或撤回已发奖励。

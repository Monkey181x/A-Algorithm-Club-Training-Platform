# 称号、徽章与特殊主题

## 商品和佩戴

管理员可在商店配置称号的文字、颜色、字体、样式、RBC Coins 价格与有效时长，保存前可预览。新增霓虹描边、金属徽章、流光、星环等固定安全样式，不接受任意 CSS。所有商品都可直接上架或下架。

购买后进入全局背包，在各团队的个人信息中独立选择佩戴。徽章、称号、头像框可分别选择；名字前显示徽章和称号。商店外观跨团队拥有，原有团队授予称号仍只在所属团队生效。购买不自动更换当前佩戴。

商品详情支持排行榜、个人名片试戴，不扣币、不改变当前装扮。商店与背包支持“全部 / 装扮”分类。管理员可以在团队成员或全局账号管理中发放、收回外观。请求重试复用请求编号，不重复扣币、扣库存或发放。

## 塔菲主题

塔菲主题改变本人看到的整站调色与背景，不更改其他成员的外观，不替换原页面布局。原自定义主题独立保存，选择普通色板可退出特殊主题。

主题附赠原版小塔菲头部徽章和护目镜头像框。徽章通过 SVG 裁切原图去除身体，保留原有头部和头发；头像框沿用原图护目镜配色，适配圆角方形头像。最终不发放重画版徽章。

已拥有的主题显示在设置色板下方独立一行，点击头像切换，沿用实色双波动画，并尊重关闭动画、减少动态效果设置。购买后刷新外观库。总览和设置的底层可显示主题背景，卡片保持可读底色。

首次迁移会为已有启用 Coins 的团队创建未上架的塔菲主题，价格 1 为占位，管理员应先调整实际价格再上架。新增团队可自行添加主题商品。

## 有效时长

主题与商店称号的 `cosmetic_duration_days` 为 0 表示永久，1–36500 表示指定天数。购买或管理员发放成功时起算，保存时长与到期时间快照。商品以后改时长或样式，不改变既有权益；已有记录保持永久。

到期后不能继续使用或佩戴，可以重新购买；有限期续购按原到期时间继续累加。永久外观不可重复购买；有限期外观和称号现已支持续期，一次限一件或一套。购买与硬币流水保留。附赠徽章、头像框跟随该次主题有效期；另有有效来源时继续保留。

下架不影响已拥有物品；收回来源库存则禁用该来源权益。已有购买或发放记录的商品不能改称号文字，应另建商品。到期由服务器判断，页面按最近到期时间清除失效外观并刷新状态，无需新增定时任务。

## 界面和修复

总览在本周积分下方增加有效提交，统一数字与分母样式，不补前导零。补充洛谷、AtCoder 平台图标。缩小商品卡片，保留详情操作。修复管理员发放背包物品时在部分访问环境中请求编号生成失败的问题，以及特殊主题背景被页面底色遮挡的问题。

## 更新服务器

本次包括 0059–0064 数据库迁移，不能只覆盖前端。0064 合并扩展分类与装扮功能的迁移分支，不增加额外数据变更。先备份数据库、媒体和当前程序，执行 `python manage.py migrate` 与 `python manage.py collectstatic --noinput`，同步重启 Web、worker、beat，保留原配置和数据。

迁移新增全局外观归属、购买有效期快照与头像框字段。0063 给已有有效来源的塔菲主题持有者补发头像框，不扣币、不改变佩戴选择。历史兼容迁移会清理曾在本地预览中出现的重画版徽章权益、下架对应旧商品，保留购买及硬币流水。

不需要新增容器。回退前保留新表和数据，勿直接反向迁移删除用户权益。本次未实现牛客 1v1 或观众下注。

## RBC 挂坠赠品（0065）

实物类商品可以在管理员编辑窗口设置“赠送永久徽章 → RBC 挂坠纪念徽章”。购买成功或管理员发放该商品后，在同一事务中自动授予全局永久徽章，不改变物品库存和派发流程，不自动替换当前佩戴。用户可在个人信息或背包中选择佩戴；名字前的展示规则与原徽章一致。重复购买和请求重试只保留一枚，商品后续改名、取消赠品或完成派发不会收回已获得的永久徽章。

0065 迁移会给名称规范化后精确为“RBC挂坠”的已有实物商品启用赠品（忽略大小写、空白和全半角）。不新建商品、不改价格或库存；不同名称可由管理员手动选择。存在未回收购买记录的历史购买者补发一次，全部已回收的记录不补发。后续购买按商品保存的配置判断，不依赖商品名称。

徽章使用用户提供的原 PNG，未重绘。赠品归属单独记录购买来源，不伪造额外的实物背包库存。更新前备份并迁移至 0065、收集静态文件，再重启原有服务即可。


## 通用资源库（0066）

主题、徽章、头像框现支持管理员直接制作或上传主题包，不再依赖新增静态注册表。商品可引用多项装扮并分别设置天数；主题到期后，仍有效的徽章和头像框继续保留。新资源的配置、预览、版本与历史兼容规则，以 [通用装扮与主题包 v1](cosmetic-packages.md) 为准。

# DJGun

## 管理员安装

1. 部署本目录，并保留 PR 中首页新增的 CSS、JS 引用。
2. 在“装扮管理 → 上传主题包”导入 `DJGun-theme.zip`。
3. 创建装扮商品，选择 `djgun` 资源，再上架、购买或发放。

ZIP 仅含配置和图片。单独导入可以登记主题资源，但完整轮播与外观依赖第一步的模块部署。
资源标识 `djgun`，名称 `DJGun`，说明留空，有效期永久；图标透明 PNG，海报 1920×1080。

模块仅在 DJGun 启用时生效；退出后恢复原版 ATLAS 装饰。保留原版业务逻辑与布局。
删除首页两个资源引用和本目录即可移除模块。

素材由贡献者提供，公开分发权限需在合并前确认。最终浏览器视觉检查尚待完成。

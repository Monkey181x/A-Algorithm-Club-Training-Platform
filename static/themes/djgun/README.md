# DJGun 外观插件

通过原站主题包机制启用，作用域为 `html[data-special-theme="djgun"]`。

## 安装

1. 部署本目录及首页两个带 `data-djgun-plugin` 的 head 引用。
2. 在原站“装扮管理 / 主题包”导入本目录的 `DJGun-theme.zip`。
3. 沿用原站商品创建、购买、发放和启用流程。导入包不会自动创建团队商品。

## 范围

仅新增独立主题目录和首页两个资源引用。原站业务文件、首页 body、文字、布局和原版动画文件不改动。
DJGun 启用时隐藏 ATLAS 原装饰，并预加载六帧，通过两张 140px 装饰图片每 1.8 秒交叉淡化。
退出主题时移除插件图片和计时器，恢复原版动画。尊重减少动态效果设置。

主材质为 70% 奶油色、深灰蓝字、暖金强调色，关闭背景模糊以统一清晰度。
商品重叠说明区使用实心底以防图片边界透出；禁用控件仍由原站逻辑控制。
默认头像保留原站首字符生成逻辑，仅覆盖底色和字色。主题图片在原槽内缩放。
设置贴纸使用透明 PNG（由提供的角色贴纸经图像工具处理），原图亦保留。

## 移除

删除首页两个引用及本目录。无需恢复业务文件。

## 验证状态

提交前运行原站前端测试及本地插件检查。桌面、手机的最终浏览器验证仍待完成；
本地安装脚本受 Docker/浏览器进程权限限制，因此以草稿 PR 提交供审查。
